# Pipeline.Import.MySQL

Pipeline.Import.MySQL is a module to import data into a MySQL database.

Installation
------------

* Install Pipeline.Import.MySQL with Composer or with your own installer.
* Pipeline.Import.MySQL follows the [semantic versioning][2] standards.

Community
---------

* Follow us on [GitHub][3].

Contributing
------------

Pipeline.Import.MySQL is an Open Source, community-driven project. Join by contributing code or documentation.

If you encounter any issues when using Pipeline.Import.MySQL you can report them [on github][4]
